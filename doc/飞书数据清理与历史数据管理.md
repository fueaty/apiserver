# 飞书数据清理与历史数据管理

## 问题背景

在使用飞书多维表格存储采集数据时，遇到了 `RecordExceedLimit` 错误，这是因为飞书表格有记录数量限制（通常为10万条记录）。随着数据不断积累，表格逐渐接近容量上限，导致新的数据无法写入。

## 解决方案

### 1. 历史数据目录结构调整

**变更内容：**
- 创建了 `history_data` 目录用于存储历史JSON数据文件
- 将原有的分散在项目根目录的 `_headlines_data.json` 文件全部移至 `history_data` 目录
- 更新了相关脚本的文件路径引用

**涉及文件：**
- `/root/apiserver/history_data/` - 新建的历史数据存储目录
- `/root/apiserver/script/export_today_headlines.py` - 修改了文件输出路径
- `/root/apiserver/script/analyze_history_data.py` - 新增历史数据分析脚本
- `/root/apiserver/script/manage_history_data.py` - 新增历史数据管理脚本

### 2. 飞书表格数据清理机制

#### 2.1 智能清理脚本 (`smart_cleanup.py`)

**功能特点：**
- 自动检测表格当前记录数量
- 根据记录数量动态调整清理策略
- 分级别处理：
  - < 8万条：状态正常，无需清理
  - 8-9.5万条：警告状态，保留60天数据
  - > 9.5万条：危险状态，保留30天数据

**使用方法：**
```bash
cd /root/apiserver
PYTHONPATH=/root/apiserver python script/smart_cleanup.py
```

#### 2.2 定时清理脚本 (`scheduled_cleanup.sh`)

**功能特点：**
- 每天凌晨2点自动执行
- 保留最近90天的数据
- 记录执行日志
- 企业微信通知执行结果

**定时任务配置：**
```
0 2 * * * /root/apiserver/script/scheduled_cleanup.sh
```

#### 2.3 手动清理脚本 (`cleanup_feishu_data.py`)

**功能特点：**
- 支持自定义保留天数
- 支持自定义批处理大小
- 详细的过程日志
- 企业微信通知

**使用方法：**
```bash
# 保留60天数据，每批处理1000条
python script/cleanup_feishu_data.py --days 60 --batch-size 1000

# 同时执行数据备份
python script/cleanup_feishu_data.py --days 90 --backup
```

### 3. 历史数据分析工具

#### 3.1 历史数据统计分析 (`analyze_history_data.py`)

**功能特点：**
- 统计历史数据的时间分布
- 分析每日数据量变化
- 检查字段一致性
- 分析站点分布情况
- 热度值统计分析

**使用方法：**
```bash
cd /root/apiserver/script
python analyze_history_data.py
```

#### 3.2 历史数据管理 (`manage_history_data.py`)

**功能特点：**
- 移动过期文件到历史目录
- 清理空的历史目录
- 备份历史数据
- 列出历史文件信息

**使用方法：**
```bash
# 列出最近10个历史文件
python manage_history_data.py list --limit 10

# 移动30天前的文件到历史目录
python manage_history_data.py move --days 30

# 备份历史数据
python manage_history_data.py backup
```

## 使用建议

### 日常维护
1. **自动清理**: 依靠定时任务自动维护，无需人工干预
2. **监控通知**: 通过企业微信及时了解清理状态
3. **定期检查**: 建议每周手动执行一次智能清理检查

### 紧急处理
当出现 `RecordExceedLimit` 错误时：
1. 立即执行智能清理：`python script/smart_cleanup.py`
2. 根据情况调整保留天数
3. 必要时可临时增加清理频次

### 数据备份
1. 历史JSON文件已集中存储在 `history_data` 目录
2. 定期执行：`python manage_history_data.py backup`
3. 建议每月进行一次完整备份

## 注意事项

1. **权限配置**: 确保飞书应用具有足够的API权限
2. **网络稳定性**: 清理过程需要稳定的网络连接
3. **执行时间**: 大量数据清理建议在业务低峰期执行
4. **监控告警**: 关注企业微信通知，及时处理异常情况
